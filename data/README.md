# Dataset Information

This directory contains the dataset used in this empirical evaluation:

- **Filename:** `cybersecurity_attacks.csv`
- **Original Source:** Kaggle Public Dataset by Team Incribo
- **URL:** [https://www.kaggle.com/datasets/teamincribo/cyber-security-attacks](https://www.kaggle.com/datasets/teamincribo/cyber-security-attacks)
- **Record Count:** 40,000 log records
- **Temporal Coverage:** January 1, 2020 – October 11, 2023 (1,380 continuous calendar days)
- **Feature Space:** 25 heterogeneous attributes across network identifiers, packet metadata, defense telemetry, user profiles, and threat labels.
